# Comparación seguro de auto 2026–2027

Comparativo de AXA Colpatria, MAPFRE y Seguros Bolívar: coberturas, deducibles y costo total del año.

Abre `index.html` en el navegador, o publícalo con GitHub Pages:

1. Crea un repositorio y sube `index.html`.
2. En **Settings → Pages**, elige la rama `main` y la carpeta `/ (root)`.
3. Queda en `https://<usuario>.github.io/<repositorio>/`.

Las primas que escribas en la página se guardan solo en tu navegador.
